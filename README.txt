## Adding the screenshots
The page currently shows two aesthetic placeholders under **"Screenshot of my results"**.

To display your actual screenshots:
1. Put the first screenshot in `assets/results-01.png`.
2. Put the second screenshot in `assets/results-02.png`.
3. In `index.html`, replace each `.image-placeholder` block with an `<img>` element, for example:
   `<img src="assets/results-01.png" alt="Carbon footprint calculator result screenshot 1">`

The project can be opened directly by double-clicking `index.html`.
